This checklist maps the server common security requirements V3.0 R1 of the Korean NIS national security requirements for information protection systems and network equipment (parts 1-2, 2023-08-21) onto checkable items for a Go module; each item's ref column points at the official clause. It does not replace the official text; manual items must be verified by a person against that text. Part 3 product-group requirements (intrusion prevention products and the like) apply additionally when the migrated system is such a product and are out of scope here.
